最新开发版（源码）
==================

如果你打算直接为最新的 ROS 2 开发做贡献，可以通过源码构建或安装测试版二进制包来安装 ROS 2。
这样你将获得最新的错误修复和功能。

测试版二进制包
--------------

参见 :doc:`测试 <../Testing>`。

从源码构建
----------

.. note::

   最新开发版没有经过与正式版本相同的严格测试，如果你需要稳定版本的 ROS 2，不推荐使用它。
   相反，请选择一个已经发布的 :doc:`ROS 发行版 <../../Installation>`。

请点击下面的链接，查看适用于你平台的最新安装说明：

* :doc:`Ubuntu Linux <Ubuntu-Development-Setup>`
* :doc:`macOS <macOS-Development-Setup>`
* :doc:`Windows <Windows-Development-Setup>`

关于如何让你的源码保持最新，请参阅 :doc:`维护源码检出 <../Maintaining-a-Source-Checkout>`。
