最新开发版（源代码）
====================

如果你计划直接为最新的 ROS 2 开发做贡献，可以通过从源代码构建或安装测试二进制包来安装 ROS 2。
这样你将获得最新的错误修复和功能。

测试二进制包
------------

参见 :doc:`测试 <../Testing>`。

从源代码构建
------------

.. note::

   最新开发版不会像正式发行版那样经过同样严格的测试，如果你正在寻找稳定的 ROS 2 版本，不建议使用它。
   相反，请选择一个已经发布的 :doc:`ROS 发行版 <../../Installation>`。

点击下方链接查看适用于你平台的最新安装说明：

* :doc:`Ubuntu Linux <Ubuntu-Development-Setup>`
* :doc:`Windows <Windows-Development-Setup>`
* :doc:`RHEL <RHEL-Development-Setup>`
* :doc:`macOS <macOS-Development-Setup>`

关于保持源代码最新，请参见 :doc:`维护源代码检出 <../Maintaining-a-Source-Checkout>`。
