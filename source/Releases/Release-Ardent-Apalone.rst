Ardent Apalone (``ardent``)
===========================

.. contents:: 目录
   :depth: 2
   :local:

欢迎来到首个非 Beta 版本的 ROS 2 软件，名为 *Ardent Apalone*！

支持的平台
----------

此版本的 ROS 2 在三个平台上受支持：


* Ubuntu 16.04 (Xenial)
* Mac macOS 10.12 (Sierra)
* Windows 10

为全部 3 个平台提供了二进制软件包以及从源代码编译的说明（参见 `安装说明 <../../Installation>` 以及 `文档 <https://docs.ros2.org/ardent/>`__）。

+--------------+-----------------------+----------------------+--------------------+
| 必需支持                                                                         |
+--------------+-----------------------+----------------------+--------------------+
| 架构         | Ubuntu Xenial (16.04) | MacOS Sierra (10.12) | Windows 10 (VS2015)|
+==============+=======================+======================+====================+
| amd64        | X                     | X                    | X                  |
+--------------+-----------------------+----------------------+--------------------+
| arm64        | X                     |                      |                    |
+--------------+-----------------------+----------------------+--------------------+

最低语言要求：

- C11[^2]
- C++14
- Python 3.5

[^2]: C11 是必需的，但也为一些不完全兼容的系统提供了支持，例如 MSVC。

功能
----

此 ROS 2 版本中的新功能
^^^^^^^^^^^^^^^^^^^^^^^^


* 分布式发现、发布 / 订阅、请求 / 响应通信

  * 由 C API 提供
  * 使用不同厂商实现：

    * eProsima 的 Fast RTPS 以及 ADLINK 的 OpenSplice（来自二进制和源代码）
    * RTI 的 Connext（仅来自源代码）

  * 用于处理非理想网络的众多服务质量设置
  * DDS Security 支持（使用 Connext 和 Fast RTPS）

* C++ 和 Python 3 客户端库

  * 用 C 共享公共代码以统一实现
  * 执行模型与节点分离，可组合节点
  * 节点特定参数（目前仅 C++）
  * 生命周期（目前仅 C++）
  * 可选地使用相同 API 的进程内通信（仅 C++）

* 消息定义（带有有界数组和字符串以及默认值）
* 命令行工具（例如 ``ros2 run``）
* 带有若干显示类型的 ``rviz`` （Windows 版本可能会在几周后跟进）
* 基于文件系统的资源索引（无需递归爬取即可查询信息）
* 用于发布 / 订阅的实时安全代码路径（仅适用于兼容的 DDS 实现）
* ROS 1 和 ROS 2 之间的桥接
* HSR 演示 `参见 Beta 3 <Beta3-Overview>`
* Turtlebot 演示 `参见 Beta 2 <Beta2-Overview>`

更详细的描述请参见 `功能 <../../The-ROS2-Project/Features>` 页面。

自 Beta 3 版本以来的变更
^^^^^^^^^^^^^^^^^^^^^^^^

自 Beta 3 版本以来的改进：


* ``rviz``
* C++ 中消息数据结构的不同初始化选项（参见 `设计文档 <https://design.ros2.org/articles/generated_interfaces_cpp.html#constructors>`__）
* 日志 API 改进，现也用于演示中
* C++ 中带不同时钟的时间支持
* Python 客户端库中的 wait-for-service 支持
* `REP 149 <https://reps.openrobotics.org/rep-0149/>`__ 的草案实现，规定了软件包清单文件的格式 3

已知问题
--------


* Fast RTPS 在处理较大数据（如图像演示）时性能不佳
* 使用 Connext 时，目前不允许两个具有相同基础名称但不同命名空间的话题具有不同类型（参见 `issue <https://github.com/ros2/rmw_connext/issues/234>`__）。
* 节点名称的列出（例如使用 ``ros2 node list``）在某些 rmw 实现之间无法工作。
* 在 Windows 上，尝试使用 ``Ctrl-C`` 中止时 Python 启动文件可能会挂起（参见 `issue <https://github.com/ros2/launch/issues/64>`__）。为了继续使用被挂起命令阻塞的 shell，你可能想使用进程监视器结束挂起的 Python 进程。
