Bouncy Bolson (``bouncy``)
==========================

.. contents:: 目录
   :depth: 2
   :local:

*Bouncy Bolson* 是 ROS 2 的第二个版本。

支持的平台
----------

此版本的 ROS 2 在四个平台上受支持（完整详情参见 `REP 2000 <https://reps.openrobotics.org/rep-2000/#bouncy-bolson-june-2018-june-2019>`__）：


* Ubuntu 18.04 (Bionic)

  * 为 amd64 以及 arm64 提供 Debian 软件包

* Ubuntu 16.04 (Xenial)

  * 没有 Debian 软件包，但支持从源代码构建

* Mac macOS 10.12 (Sierra)
* Windows 10 with Visual Studio 2017

提供了二进制软件包以及从源代码编译的说明（参见 `安装说明 <../../Installation>` 以及 `文档 <https://docs.ros2.org/bouncy/>`__）。

功能
----

此 ROS 2 版本中的新功能
^^^^^^^^^^^^^^^^^^^^^^^^


* `新的 launch 系统 <../Tutorials/Intermediate/Launch/Launch-system>`，具有更强大、更灵活的 Python API。
* 参数可以作为 `命令行参数 <../How-To-Guides/Node-arguments>` 传递给 C++ 可执行文件。
* 通过 `命令行参数 <../How-To-Guides/Node-arguments>` 进行静态重映射。
* 对 Python 客户端库的各种改进。
* 支持发布和订阅序列化数据。
  这是即将开展的本地 rosbag 实现工作的基础。
* 更多 `命令行工具 <../../Concepts/Basic/About-Command-Line-Tools>`\ ，例如用于处理参数和生命周期状态的工具。
* 二进制软件包 / fat 归档默认支持三种 RMW 实现（无需从源代码构建）：

  * eProsima 的 Fast RTPS（默认）
  * RTI 的 Connext
  * ADLINK 的 OpenSplice

有关所有可用功能的概述，包括早期版本中的功能，请参见 `功能 <../../The-ROS2-Project/Features>` 页面。

自 Ardent 版本以来的变更
^^^^^^^^^^^^^^^^^^^^^^^^

自 `Ardent Apalone <Release-Ardent-Apalone>` 版本以来的变更：


* Python 软件包 ``launch`` 已重新设计。
  之前的 Python API 已移入子模块 ``launch.legacy``。
  如果不想过渡到新的 Python API，你可以更新现有 launch 文件以继续使用旧版 API。
* 包含命名空间的 ROS 话题名称会映射到包含其命名空间的 DDS 话题。
  DDS 分区不再用于此目的。
* 推荐的构建工具现在是 ``colcon`` 而非 ``ament_tools``。
  此切换对每个 ROS 2 软件包中的代码没有 `影响 <https://design.ros2.org/articles/build_tool.html#implications>`__。
  安装说明已更新，`read-the-docs 页面 <https://colcon.readthedocs.io/en/main/migration/ament_tools.html>`__ 描述了如何将现有的 ``ament_tools`` 调用映射为 ``colcon``。
* `此 rclcpp::Node::create_subscription() 签名 <https://docs.ros2.org/bouncy/api/rclcpp/classrclcpp_1_1_node.html#a283fb006c46470cf43a4ae5ef4a16ccd>`__ 的参数顺序已修改。

已知问题
--------


* 对于某些平台和 RMW 实现的组合，新式 launch 文件 `可能在关闭时挂起 <https://github.com/ros2/launch/issues/89>`__。
* 当针对特定节点时，命名空间的静态重映射 `无法正确工作 <https://github.com/ros2/rcl/issues/262>`__。
* 使用 ``ros2 param`` 和 ``ros2 lifecycle`` 命令行工具时，`可能会打印 Opensplice 错误消息 <https://github.com/ros2/rmw_opensplice/issues/237>`__。
