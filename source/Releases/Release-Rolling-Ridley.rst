Rolling Ridley (``rolling``)
============================

.. contents:: 目录
   :depth: 2
   :local:

*Rolling Ridley* 是 ROS 2 的滚动开发发行版。

.. warning::

  Rolling Ridley 会持续更新，并会进行就地更新，这些更新有时会包含破坏性变更。
  它用于 ROS 2 开发，也供那些希望自己的软件包能发布并为下一个稳定发行版做好准备的维护者使用。
  我们建议大多数 ROS 2 用户使用最新的 `稳定发行版 <latest-release>`。

更多信息请参见 `REP-2002 <https://reps.openrobotics.org/rep-2002/>`_

当前支持的平台
--------------

根据 `平台支持等级 <../The-ROS2-Project/Platform-Support-Tiers>`，Rolling Ridley 支持以下平台：

一级平台：

* Ubuntu 24.04 (Noble)：``amd64`` 和 ``arm64``
* Windows 10 (Visual Studio 2019)

三级平台：

* Debian Buster (10)：``amd64``、``arm64`` 和 ``arm32``
* Mac macOS 10.14 (Mojave)
* OpenEmbedded Thud (2.6) / webOS OSE：``arm32`` 和 ``x86``

安装
----

`安装 Rolling Ridley <../../Installation>`

本版本的新功能和变更
--------------------

Rolling Ridley 是一个持续开发的发行版。
当前稳定发行版与即将发布的版本之间的变更可在 `即将发布的版本 <upcoming-release>` 页面上找到。
