URDF
====

URDF（Unified Robot Description Format，统一机器人描述格式）是一种文件格式，用于指定 ROS 中机器人的几何结构和组织方式。
URDF 文件遵循 XML 格式，如 `这里 <https://wiki.ros.org/urdf/XML>`_ 所述。
