指标
====

.. contents:: 目录
   :depth: 2
   :local:


虽然我们不追踪 ROS 用户，但我们会衡量 ROS 社区的各个方面，以了解和跟踪我们工作的影响，并找出需要改进的地方。


实时项目指标
------------

- `metrics.ros.org <https://metrics.ros.org>`_ 是一个网站，托管着相当及时的 ROS 社区指标可视化。
- `Linux Foundation 的 ROS LFX 仪表盘 <https://insights.linuxfoundation.org/project/ros?>`_ 包含最新的贡献者、开发、受欢迎程度和项目健康指标。
- `我们的 OSU OSL AWStats 仪表盘 <https://awstats.osuosl.org/reports/packages.ros.org/2026/01/awstats.packages.ros.org.html>`_ 提供 ROS 包下载的实时数据。

*请注意，你需要在 AWStats URL 中指定当前月份和年份才能获得最新信息。*

- Github 维护着带有 `#ROS <https://github.com/topics/ros>`_ 和 `#ROS2 <https://github.com/topics/ros2>`_ 标签的完整包和项目列表。
- 原始 `ROS 论文 <https://scholar.google.com/scholar?cites=1227661396257612398&as_sdt=2005&sciodt=0,5&hl=en>`_ （`Quigley et al., 2009 <http://lars.mec.ua.pt/public/LAR%20Projects/BinPicking/2016_RodrigoSalgueiro/LIB/ROS/icraoss09-ROS.pdf>`_）和权威 `ROS 2 论文 <https://scholar.google.com/scholar?oi=bibs&hl=en&cites=1227661396257612398&as_sdt=5>`_ （`Macenski et al., 2022 <https://www.science.org/doi/abs/10.1126/scirobotics.abm6074>`_）的最新引用列表都可在 Google Scholar 上获取。

定期指标报告
------------

我们会定期发布指标报告，提供 ROS 社区的量化视图。
我们正在共同学习要衡量什么以及如何衡量，并随着系统的变化而演变。
请提供反馈！
请将你关于如何改进这些报告的建议发布到 `Open Robotics Discourse Site Feedback 类别 <https://discourse.openrobotics.org/c/site-feedback/3>`_。
