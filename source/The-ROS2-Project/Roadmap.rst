------------

Lyrical 路线图
--------------

正在开发的功能在 `GitHub Project Board <https://github.com/orgs/ros2/projects/70>`__ 上进行跟踪。
路线图中的条目是 ROS 2 社区正在开发的主要功能。
“大小”是对任务规模的估计，其中 *Small* 表示需要数人天完成，*Medium* 表示需要数人周完成，*Large* 表示需要数人月完成。

如果你正在为 ROS 2 开发某个功能并希望将其列出，请在 `ROS 2 Documentation <https://github.com/ros2/ros2_documentation>`__ 上提交 issue。
如果你想承担其中某个任务，请 :doc:`与我们联系 <../Contact>`。

为 ROS 2 做贡献
---------------

想找点事做，或者只是想帮忙？
以下是一些可以让你上手的资源。

1. :doc:`贡献 <Contributing>` 指南描述了如何为 ROS 2 做出贡献。
2. 查看 :doc:`功能创意 <Feature-Ideas>` 列表寻找灵感。
3. 关于 ROS 2 设计的更多信息，请参阅 `design.ros2.org <https://design.ros2.org>`__。
4. ROS 2 的核心代码位于 `ros2 GitHub 组织 <https://github.com/ros2>`__ 中。
5. 讨论 ROS 2 设计的论坛是 `Open Robotics Discourse 的 ROS 类别 <https://discourse.openrobotics.org/c/ros/111>`__。
6. 问题应该在 `Robotics Stack Exchange <https://robotics.stackexchange.com/>`__ 上提出\ ，请务必至少包含 ``ros2`` 标签以及你正在运行的 rosdistro 版本，例如 ``{DISTRO}``。
