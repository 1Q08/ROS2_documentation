关于 ROS
========

ROS（Robot Operating System，机器人操作系统）是一个开源生态系统，为构建、部署、运行和维护机器人应用提供框架、工具和库。
本文介绍该生态系统的主要组成部分，并概述它们的预期用途。

**领域：ROS 框架、ROS 工具、ROS 能力 | 内容类型：简介 | 难度：入门**

概述
----

ROS 被应用于机器人学的众多领域。
在物流领域，ROS 通过提供导航、建图、运动控制以及多机器人之间的协调，帮助机器人在仓库中搬运货物。
在制造业领域，ROS 支持自动化抓取与放置（pick-and-place）等高级任务，借助视觉系统实现精准操作。
在医疗领域，ROS 支撑着辅助患者护理、提升临床工作流程效率的机器人系统。

观看 `ROS 视频`_ 快速了解 ROS。

生态系统
--------

尽管名为"操作系统"，但 ROS 实际上并非传统意义上的操作系统，而是一套工具和库的集合，帮助开发者使用各种平台和编程语言来创建机器人。

框架
----

ROS 框架是让机器人各部分之间、以及各部分内部能够相互通信的"管道"。
它包括消息传递、标准接口，以及对多种编程语言和平台的支持。

例如，该框架负责把数据从摄像头发送到处理节点，或将规划系统的命令传递给电机控制器。
它还提供了跨系统共享软件的机制，使开发者能够构建模块化、可复用的解决方案。

ROS 由以下基本组件组成：

* 节点（Nodes）
* 接口（Interfaces，包括话题 topics、服务 services 和动作 actions）
* 参数（Parameters）
* 客户端库（Client libraries）

工具
----

ROS 中的工具帮助开发者构建、测试和监控机器人系统。
它们不添加新的机器人行为，而是让开发变得更加容易。

例如，可视化工具可以在测试期间以 3D 方式展示机器人的传感器、位置和环境，这在无人机或移动机器人项目中十分常见。
借助启动控制工具，开发者可以在实际部署之前定义并验证机器人的启动方式与运行管理。
数据记录与回放工具让你能够记录机器人的行为以供事后检查，这在调试机器人为何出错时尤其有用。

ROS 提供的核心工具集能够帮助你处理开发工作流中的以下环节：

* 内省（Introspection）
* 分析（Analysis）
* 节点管理（Node management）
* 调试（Debugging）
* 构建（Builds）
* 可视化（Visualization）
* 包文档（Package documentation）

能力
----

ROS 中的"能力"（Capabilities）是即开即用的软件包，为机器人提供诸如操作、运动规划和感知等常用功能。
这些软件包让开发者无需从零开始即可添加高级行为。

例如，操作类软件包可以控制机械臂，完成自动化工作流中的抓取与放置等任务。
运动规划类软件包通过计算机器人环境中的安全路径，让机器人能够从一个点移动到另一个点。
感知类软件包使机器人能够检测和识别物体或人员，从而支持取回物品等任务，或在机器人需要对所见作出响应的环境中工作。
同一能力的不同实现允许开发者切换实现并进行试验，以找到最适合自身需求的实现。

.. note::
    除了 Open Robotics 维护的软件包之外，你还可以从 ROS 社区贡献的大量软件包中进行选择。

ROS 以开箱即用或通过受支持的第三方解决方案的方式，提供以下核心能力：

* 仿真（Simulation）
* 运动规划（Motion planning）
* 导航（Navigation）
* 操作（Manipulation）
* 感知（Perception）

社区
----

ROS 社区是由开发者、研究人员、公司和贡献者组成的全球网络，他们共同推动我们开源软件库的成长与完善。
人们可以为"管道"、工具和能力做出贡献，而正是得益于社区，共享代码、交流想法以及协同开展项目都变得十分容易。

集成
----

ROS 与其他 Open Robotics 平台协同工作，使开发和部署更加容易。

* `Gazebo`_：提供基于物理的仿真，让开发者能够在虚拟环境中测试机器人，而无需先使用真实硬件。
* `Open-RMF`_ （Robotics Middleware Framework，机器人中间件框架）：帮助不同的机器人协同工作，并与电梯、门等楼宇系统进行交互。
* `ros-controls`_：支持使用 ROS 对机器人进行实时控制。

.. _Gazebo: https://gazebosim.org/home
.. _Open-RMF: https://www.open-rmf.org/
.. _ros-controls: https://control.ros.org/rolling/index.html

这些集成让在各种预算和团队规模下，于复杂环境中设计、测试和管理机器人都变得更加简单。

ROS 发行版
----------

ROS 发行版是按固定周期发布的一组打包好的 ROS 软件。
每个发行版都提供核心库和工具的稳定版本，外加许多社区软件包。
这使得开发者能够基于一致的代码库进行开发，并保持项目的兼容性。

ROS 有两个主要版本：

* `ROS 1`_：最初的框架。
* ROS 2：当前正在积极开发的版本。

.. _ROS 1: https://index.ros.org/

ROS 1 的开发已终止，不再有新的发布计划；而 ROS 2 仍在持续开发，并每年发布新的发行版。
这些发行版包含更新与改进，因此开发者可以在稳定性和最新特性之间做出选择。

支持的系统
----------

ROS 可运行于 Ubuntu、Windows 和 macOS，但我们强烈建议为你的 ROS 发行版使用 Tier 1 平台。
macOS 上的 ROS 由社区支持，我们不建议新用户使用。

对 Ubuntu 的支持取决于 ROS 发行版，每个发行版都要求特定的 Ubuntu LTS（长期支持）版本。
其他平台可能需要从源代码构建或使用容器。
