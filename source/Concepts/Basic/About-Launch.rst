启动
====

.. contents:: 目录
   :local:

一个 ROS 2 系统通常由许多节点组成，这些节点运行在许多不同的进程中（甚至不同的机器上）。
虽然可以手动逐个启动这些节点，但这很快就会变得繁琐。

ROS 2 中的启动（launch）系统旨在通过一条命令自动运行多个节点。
它帮助用户描述其系统的配置，然后按描述执行。
系统的配置包括：要运行哪些程序、在哪里运行它们、向它们传递哪些参数，以及一些 ROS 特有的约定——这些约定通过为每个组件赋予不同的配置，使得在整个系统中复用组件变得容易。
它还负责监控被启动进程的状态，并对这些进程的状态变化进行报告和/或做出反应。

上述所有内容都在一个“启动文件（launch file）”中指定，该文件可以用 XML、YAML 或 Python 编写。
随后可以使用 ``ros2 launch`` 命令运行该启动文件，其中指定的所有节点都会被运行。

要开始编写和使用启动文件，请参阅 `启动教程 <../../Tutorials/Intermediate/Launch/Launch-Main>`。

更多详细信息，请参阅 `启动文档 <https://docs.ros.org/en/{DISTRO}/p/launch>`__。
