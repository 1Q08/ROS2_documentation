发现
====

.. contents:: 目录
   :local:

节点的发现是通过 ROS 2 底层中间件自动完成的。
可以概括如下：

#. 节点启动时，会向网络中同一个 ROS 域（由 ROS_DOMAIN_ID 环境变量设置）内的其他节点通告自己的存在。
   节点会响应这一通告，提供自己的信息，从而建立合适的连接，使节点之间能够通信。
#. 节点会定期通告自己的存在，以便即使在最初的发现阶段结束后，也能与新发现的实体建立连接。
#. 节点在离线时会向其他节点通告。

只有当其他节点具有兼容的 :doc:`服务质量 <../../Tutorials/Demos/Quality-of-Service>` 设置时，节点才会与其建立连接。

以 :ref:`talker-listener 示例 <talker-listener>` 为例。
在一个终端中运行 C++ talker 节点，它会在某个话题上发布消息，
而在另一个终端中运行的 Python listener 节点会订阅同一话题上的消息。

您应该会看到这两个节点自动发现彼此，并开始交换消息。
