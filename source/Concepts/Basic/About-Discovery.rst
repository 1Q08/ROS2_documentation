发现
====

.. contents:: 目录
   :local:

节点的发现（discovery）通过 ROS 2 的底层中间件自动进行。
其过程可概括如下：

#. 当一个节点启动时，它会向网络上具有相同 ROS 域（由 ROS_DOMAIN_ID 环境变量设置）的其他节点宣告自己的存在。
   其他节点对此宣告做出响应，返回自身的信息，从而建立适当的连接并相互通信。
#. 节点会周期性地宣告自己的存在，以便即使在初始发现期之后，也能与新出现的实体建立连接。
#. 当节点下线时，也会向其他节点宣告。

只有当节点之间具有兼容的 :doc:`服务质量 <../../Tutorials/Demos/Quality-of-Service>` 设置时，它们才会建立连接。

以 :ref:`talker-listener 示例 <talker-listener>` 为例。
在一个终端中运行 C++ talker 节点会在某个话题上发布消息，
而在另一个终端中运行的 Python listener 节点则会订阅同一话题上的消息。

你应该能看到这些节点自动发现彼此，并开始交换消息。
